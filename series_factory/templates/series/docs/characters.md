# Characters

One `##` section per character. `series canon <CODE>` prints a section; `series context` gives the relevant sections to
the script writer. Start a heading with the character's code or name.

## NARRATOR — the narrator

### Personality
(voice, attitude, what they would never say)

### Sound signature
(sfx ids in backticks, e.g. `door_creak`)
